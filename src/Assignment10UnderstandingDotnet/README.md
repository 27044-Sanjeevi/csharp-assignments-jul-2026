# Math Calculator Console Application

A simple C# console application that performs basic operations (Addition, Subtraction, Division, Multiplication) based on the user input.
This is developed as a part of Assignment 10: Understanding .NET.

## Features
- Basic Arithmetic: Supports Addition, Subtraction, Division and Multiplication of two numbers.
- Input Validation: Ensures the user enters valid integers for operation.
- Error Handling: Handles division by zero exception in case of division.

## Usage:
- Enter the first number (integer).
- Enter the second number (integer).
- Select the operator (+, -, *, /).
- The result is displayed after calculation is performed.
